# Badanie licencjackie — certyfikacja rozmów AI

Projekt badawczy realizowany w ramach pracy licencjackiej (SWPS).
Celem jest zbadanie wpływu certyfikacji rozmów AI oraz autorytetu eksperckiego
na poziom zaufania użytkowników.

System:
- symuluje rozmowę krokową z chatbotem
- generuje certyfikat rozmowy (hash + szyfrowanie)
- zapisuje dane badawcze do CSV
- umożliwia weryfikację certyfikatu

Technologie:
- Python (Flask)
- HTML / CSS / JS
- IPFS (Lighthouse)
- szyfrowanie Fernet
